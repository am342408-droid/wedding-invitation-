# Ali & Mai — Wedding Invitation

A lightweight wedding invitation website inspired by the reference invitation.

## Included
- Opening invitation screen
- Guest name from URL: `?guest=Ali`
- English / Arabic switch
- Wedding photo supplied by Ali
- Date, time and venue
- Countdown to 16 October 2026, 7:00 PM (Egypt time)
- Google Calendar button
- Directions button using the supplied Google share link
- Mobile-first responsive design

## Deploy on Vercel
1. Create a GitHub repository and upload all files in this folder.
2. Import the repository into Vercel.
3. Deploy as a static site; no build command is required.
4. Share personalized links such as:
   `https://YOUR-DOMAIN.vercel.app/?guest=Ali`

No database is required because this version does not include Guest Wishes / RSVP storage.
